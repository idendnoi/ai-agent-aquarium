# AI 에이전트 수족관

여러 AI를 동시에 쓰는 사람을 위한 **상주형 위젯 프로토타입**입니다.
화면 오른쪽 끝의 작은 수조(100 × 700px)에 Claude Code · Codex · Gemini를 캐릭터로 띄워 두고,
누가 무엇을 얼마나 하고 있는지 곁눈질로 확인하며 한 창에서 전부 관리합니다.

> 멋쟁이사자처럼 14기 기획경진대회 · 기획 검증용 프로토타입
> **모든 데이터는 목업이며 실제 API 연동은 없습니다.**

---

## 해결하려는 문제

커뮤니티(Hacker News, Reddit, Blind) 리서치로 확인한 페인포인트입니다.

| 페인포인트 | 대응 기능 |
| --- | --- |
| 탭·앱 전환 피로 | 위젯형 상주 UI, 단일 창 세션 스위칭 |
| 어느 AI가 나은지 판단 불가 | 벤치마크 스탯 3종 동시 비교 |
| 응답 대기 시간의 불투명성 | 진행 시간 · 예상 완료 시간 실시간 표시 |
| 맥락 재설명 비용 | 대화 넘기기(요약 자동 전달) |

---

## 구현된 기능

1. **위젯형 상주 UI** — 화면 우측 가장자리에 밀착하는 100 × 700 수조
2. **AI별 캐릭터화** — 클코 · 덱스 · 제미니. 이름, 픽셀 캐릭터, 성격 프리셋
3. **상태 시각화** — 작업 중 / 쉬는 중 / 지침에 따라 채도 · 기울기 · 배지가 변화
4. **시간 표시** — 진행 시간과 예상 완료 시간을 1초 단위로 갱신
5. **호버 상세 카드** — 커서를 올리면 작업 내용 · 진행률 · 남은 시간 · 최근 로그
6. **스탯 비교** — 코딩 / 추론 / 장문 / 속도 / 가격 다섯 축을 셋이 나란히
7. **자동 라우팅** — 프롬프트 유형을 판별해 담당 AI와 예상 소요 시간 · 사용량 제시
8. **통합 작업 관리** — 세 서비스 세션을 한 목록에서 전환
9. **대화 넘기기** — 다른 AI로 이관 시 맥락 요약이 함께 전달
10. **비교 분석** — 같은 프롬프트를 셋에게 동시 전송, 응답 시간 · 합의도 · 불일치 지점 산출
11. **말투 프리셋** — 캐릭터 성격에 맞춘 표현 변환(원문 병기, 기본값 꺼짐)
12. **온보딩 · 가이드 투어** — 12단계 스포트라이트 투어와 자동 재생

## 실행 방법

빌드 도구나 의존성이 없습니다. 정적 파일만으로 동작합니다.

```bash
git clone <이 저장소 주소>
cd ai-aquarium
```

`index.html`을 브라우저로 열면 끝입니다. 로컬 서버로 띄우려면:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

### 사용법

- 진입 시 온보딩에서 **가이드 투어 / 자동 재생 / 혼자 둘러보기** 중 선택
- 상단 **실제 크기** 버튼: 1920 × 1200 화면을 1:1 픽셀로 렌더링 (발표 시연용)
- 투어 중 키보드 `←` `→` 로 이동, `Esc` 로 종료

## 폴더 구조

```
ai-aquarium/
├── index.html              마크업 (데스크탑 목업 · 위젯 · 패널 · 투어)
├── assets/
│   ├── css/style.css       전체 스타일
│   ├── js/data.js          캐릭터 · 세션 · 벤치마크 목업 데이터
│   ├── js/app.js           렌더링 · 상태 · 패널 · 투어 로직
│   └── img/                캐릭터 이미지 3종
└── docs/
    └── planning.md         기획 문서
```

데이터를 바꾸려면 `assets/js/data.js` 의 `A` 배열만 수정하면 됩니다.
각 캐릭터 객체는 상태, 작업 정보(`work`), 벤치마크 점수(`stats`), 세션(`session`) 을 가집니다.

## 기술 노트

- 프레임워크 없는 순수 HTML / CSS / JavaScript
- 1920 × 1200 목업은 `transform: scale()` 로 축소하고, 투어 오버레이만 `position: fixed` 로 실제 픽셀에 그려 글자 깨짐을 방지
- 캐릭터 이미지는 배경을 제거한 투명 PNG. Gemini는 46px 그리드로 다운샘플 후 26색 팔레트로 픽셀화
- `prefers-reduced-motion` 을 존중해 모션을 끕니다

## 데이터 출처

벤치마크 수치는 Artificial Analysis 등 공개 리더보드를 참고한 **예시 값**입니다.
축마다 1위가 다르기 때문에 종합 순위는 의도적으로 산출하지 않습니다.
실제 서비스로 옮길 때는 출처와 측정 시점을 각 수치에 명시해야 합니다.

## 라이선스 확인 필요

`assets/img/` 의 캐릭터 이미지는 프로토타입 시연을 위한 임시 에셋입니다.
공개 저장소에 올리기 전 각 이미지의 저작권과 사용 범위를 확인하시고,
직접 제작한 에셋으로 교체하는 것을 권장합니다.
